
# 2D Pixel Campus Adventure Game

## Project Proposal

This application is a **2D pixel-style desktop game** with a campus-life setting and a story-driven adventure. The player takes the role of a high school student whose daily life consists of attending school, completing homework, and dealing with family relationships. One day, the character unexpectedly receives one million dollars and decides to leave school to pursue a different life. Throughout the game, the player will explore different locations, interact with characters, collect useful items, and progress through the main storyline by making choices.

This game is intended for anyone who enjoys pixel-art games and story-driven adventures. I am interested in this project because I enjoy playing games and would like to create my own original game with an engaging story and interactive gameplay.

## User Stories

- As a player, I want to be able to create my character and choose the character's name and gender.
- As a player, I want to be able to interact with different characters throughout the game.
- As a player, I want to be able to collect items and add them to my inventory.
- As a player, I want to be able to view all items currently stored in my inventory.
- As a player, I want to be able to make choices that affect the progress of the main storyline.
- As a player, I want to be able to view my current story progress.
